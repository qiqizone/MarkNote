# MarkNote

A note-taking app in OneNote style that also supports Markdown, running in the browser.

类 OneNote 的笔记应用：无限画布 + 自由拖拽的编辑区，同时兼容 Markdown。

---

## 技术栈

| 层 | 选型 |
| --- | --- |
| 构建 | Vite 5 |
| 框架 | React 18 + TypeScript |
| 富文本 | TipTap 2（ProseMirror）+ `tiptap-markdown` |
| 源码编辑 | CodeMirror 6（`@uiw/react-codemirror`） |
| 数据 | 浏览器 `localStorage`，无后端 |

## 快速开始

需要 Node.js 18 或 20。

```powershell
npm install
npm run dev       # 开发模式，http://localhost:5173
npm run build     # 类型检查 + 打包，产物在 dist/
npm run preview   # 预览打包结果，默认 4173 端口
```

> PowerShell 若提示「禁止运行脚本」，把 `npm` 换成 `npm.cmd`。

`dist/` 为纯静态文件，可直接部署到 nginx、Vercel、Netlify 或 GitHub Pages（用子路径部署时需在 `vite.config.ts` 设置 `base`）。

## 界面结构

```
┌─ 顶栏：笔记本名 · 分区 Tab · 搜索 ────────────────┐
│ 分区列表  │           画布（编辑区）    │  页面列表  │
└──────────────────────────────────────────────────┘
```

- **分区**：顶部彩色 Tab，可新建、重命名；颜色循环取色。
- **页面**：右侧页面列表，显示标题、更新时间、字数与编辑区数；支持搜索（标题 + 正文 + 文档 JSON）、右键菜单、删除。
- **数据模型**：`Notebook → Section → Page → NoteBlock`。

## 画布与编辑区

### 无限画布

画布不设边框，随内容自动撑开；编辑区用绝对坐标定位，可向右无限新增。空白处点击即可回到最后一个编辑区继续写。

### 新增编辑区

点击画布右侧的竖条「＋ 新编辑区」，会在最右侧追加一个编辑区。页面至少保留一个。

### 拖动与吸附

- 悬停编辑区左上角出现拖拽把手 `⠿`，可整体拖动位置。
- 拖动时按 8px 阈值吸附到其他编辑区的左/右/上/下/中线，并对齐时显示蓝色参考线。
- 吸附会保留 24px 间距，不贴死；吸附后若与其他编辑区冲突则不吸附。

### 调整大小

拖动编辑区右侧热区改宽度（240–1400px），双击恢复当前页面预设宽度。

### 缩放与页宽

- 缩放 50%–200%，双击百分比恢复 100%。
- 页宽三档：窄 560 / 标准 720 / 宽 900，切换时会重排所有编辑区。

## 两种编辑区类型（M / D）

悬停编辑区，左上角出现两个小圆钮，切换该编辑区自己的类型；同一画布上两种类型可以并存，互不影响。

### M —— Markdown

- 默认解析 Markdown 语法显示（标题、列表、代码块、表格、链接等）。
- 顶栏「Markdown / 源码」两个按钮只对 M 类型生效，可在预览与源码之间切换（`Ctrl+E`）。
- 不支持设置字体、颜色等格式。

### D —— 文档

- 按**纯文本**显示：`##`、`**`、`-` 等 Markdown 语法保持字面文本，不会被解析。
- 关闭了输入规则与粘贴规则，输入 `##` 也不会当场变成标题。
- 激活时顶栏出现格式条：字体、字号、颜色、加粗、斜体、下划线、删除线、左/中/右对齐、清除格式。
- 切到 D 时顶栏「Markdown / 源码」按钮呈灰色禁用（文档类型不支持源码视图）。

### 类型切换时的格式处理

- **D → M**：只切显示方式，格式数据仍保留在 `doc` 字段里，此时 M 视图按 Markdown 原文渲染，看不到颜色。
- **M → D**：把 M 里改过的文本合并回文档结构（`src/docMerge.ts`）：
  - 文本未变的段落整段复用原格式；
  - 文本有改动的段落按字符对齐，未改动的字符沿用原格式，新插入的字继承插入点格式；
  - 合并失败才退回纯文本。

  所以在 M 里改了几个字，再切回 D，原有的颜色和字体不会丢。

## 阅读模式

右上角「编辑 / 阅读」两段式切换，**默认编辑模式**（不记忆阅读状态）。

阅读模式下的表现：

- 隐藏全部编辑控件：M/D 切换、拖拽把手、删除按钮、宽度把手、格式条、状态行、新增编辑区竖条、页宽预设、Markdown/源码切换。
- 编辑区变成带 1px 边框、10px 圆角和柔和投影的白色卡片，画布转为浅灰底。
- 内容只读、标题只读，一律以 Markdown 预览呈现。
- 内容按宽度居中显示；多个编辑区时整组居中，超出可视区仍可横向滚动。
- 保留页面标题与缩放控制。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/Cmd + E` | Markdown 预览 / 源码切换（仅 M 类型） |
| `Ctrl/Cmd + S` | 立即保存到 localStorage |

输入框内支持的 Markdown 快捷语法：`## ` 标题、`- ` 列表、`> ` 引用、` ``` ` 代码块等。

## 数据存储

- 内容保存在浏览器 `localStorage`，没有服务端，也不会上传到 Git。
- 键名：`mnote.workspace.v10`（笔记数据）、`mnote.ui.v1`（当前分区/页面/视图模式）。
- 每次改动即时写入，并在 `beforeunload` / `pagehide` / 页面隐藏时兜底保存。
- 标题行显示「已保存 + 时间 + 字数 + 编辑区数」。

> 换电脑、换浏览器或换域名，数据都是独立的一份。当前尚未提供导出/导入功能。

## 目录结构

```
src/
├─ App.tsx                  # 状态管理与增删改逻辑
├─ components/
│  ├─ SectionTabs.tsx       # 顶部分区 Tab
│  ├─ PageList.tsx          # 右侧页面列表与搜索
│  └─ EditorPane.tsx        # 画布、编辑区、格式条、阅读模式
├─ docMerge.ts              # 文本改动合并回文档结构（保留格式）
├─ storage.ts               # localStorage 读写与数据归一化
├─ seed.ts                  # 首次启动的示例笔记
├─ types.ts                 # 数据模型与宽度预设
├─ styles.css               # 全部样式
└─ main.tsx                 # 入口
```

## 已知限制

- 数据只存本地浏览器，未做云端同步与多端迁移。
- 未做撤销/重做、图片粘贴、协同编辑。
- 打包产物单文件约 1.3 MB（未做代码分割）。
- 暂无自动化测试。
